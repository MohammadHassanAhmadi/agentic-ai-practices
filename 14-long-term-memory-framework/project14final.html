سه جواب که تو مصاحبه باید حاضر باشه

۱. State vs Context vs Store؟
State داده‌ی متغیر یک اجرا؛ Context هویت ثابت همون invoke؛ Store داده‌ی دائمی بین همه‌ی threadها.

۲. چرا user_id تو namespace؟
namespace مرز منطقی کوئریه. بدونش search() حافظه‌ی همه‌ی کاربرها رو برمی‌گردونه → نشت اطلاعات.

۳. چرا Runtime رو به helperها نمی‌دی؟
منطق کسب‌وکار رو به فریم‌ورک میخ می‌کنه و تست واحد رو سخت می‌کنه. helper فقط BaseStore می‌گیره.
